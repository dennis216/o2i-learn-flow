# O2I 真实题人工审核SOP（v4）

配合 [v4指南](O2I_AI_PRACTICE_WORKFLOW_V4_ZH.md)。审核仍覆盖数学、来源/使用依据、分类和实际显示，**不用逐题填四套表**。决定与修订写Decisions.json，发布人/时间由服务器记录。AI导出五项审核pending、reviewed_by/at空，不阻止保存完整未发布草稿。

## 逐题核验

| 对象 | 必查内容 | 失败处理 |
| --- | --- | --- |
| 原文与定位 | 文件名、PDF物理页、真实题号或唯一locator；题干/全选项/顺序；正负号、极限方向、上下标、图形标签；答案页和配对依据 | 转录错按原文修并记录前后值；来源印错不静默改题，排除或取得可核实勘误 |
| 数学 | 每题先不依赖AI解法独立得出答案，再核对唯一正确项、解法条件/关键推导；来源解法和AI草稿有区分 | 争议题、AI新写解法、OCR/图形风险再逐步完整核验；未解决不导出可导入题 |
| 标签 | 主Topic语义、实际考查Skills、代码存在、课程范围、表示方式、难度合理 | AI一致不代替语义检查；不确定待定，不为凑配额改难度 |
| 计算器 | 区分来源明确要求和人工政策；未指定可空 | 冲突人工决定，不能从可心算推断禁计算器 |
| 图形 | 完整清晰、对应题目、稳定授权URL；桌面/窄屏可读 | 缺图不猜，补资产后导出 |
| 使用依据 | 许可记录覆盖实际复制/学生展示；第三方图片是否另有要求 | 批次共用依据、例外单列；不明只可内部未发布草稿，禁止发布，不假装后端会自动拦截 |
| 实际显示 | Admin中题干/选项/解析公式、换行、图片、标签；学生端答案隐藏另验 | 语法检查不等于页面显示通过，先修后发 |

两次AI处理不等于人类数学批准。普通一致题也逐题核对来源、答案和解法关键条件，不能无条件批量通过。审核人可兼任角色，前提是有能力且实际完成核验。

## 只提交一份人工决定

- 保留：本次核对完成，内容、标签、必要资产完整。
- 修改后保留：修改值、依据与复核结果明确，应用后再导出。
- 排除：具体原因保留在证据中。
- 待定：没有决定或问题未解决，不进最终稿。

卡片默认无决定；明确文字列出一组题也可。未列出默认待定。Decisions逐题记录决定来源、修订前后值、问题解决依据；审核人未知空，不代填名字。许可和计算器政策可按批次引用，例外单列。修改题干/选项/答案/解析后，重新核对受影响内容。

## 证据和flags

Evidence/Independent不可覆盖。来源、AI推断、人工设定分开。ANSWER_AI_INFERRED、SOLUTION_AI_DRAFT表示来源性质，人工看过仍须可追溯；OCR_MATH_UNCERTAIN等异常有解决证据后不再列当前待办，Decisions留解决记录，不批量清空历史。

JSON不会自动随XLSX导入；重要摘要同步到source_transcription_notes、ai_inference_notes、human_review_notes，按稳定题ID归档全批文件。见 [Schema](O2I_QUESTION_IMPORT_SCHEMA.md)。

推荐flags沿用旧代码，按具体问题使用，不要求每题全部填写：

| 代码 | 含义和处理 |
| --- | --- |
| OCR_UNCERTAIN / OCR_MATH_UNCERTAIN | 对照原页核对不清文字/数学符号，不能猜字符 |
| SOURCE_LOCATOR_MISSING | 无题号且不能唯一定位；不能仅因题号为空而使用 |
| SOURCE_LOCATOR_UNVERIFIED | locator已建但未由人核对；验证后留解决记录 |
| OPTION_ORDER_UNCERTAIN | 核对原选项标签/顺序 |
| ANSWER_AI_INFERRED / SOLUTION_AI_DRAFT | 答案/解法的AI来源性质，人工核实后仍保留来历 |
| ANSWER_UNCERTAIN | 无法唯一求解，不进最终导入稿 |
| CODE_UNVERIFIED / TAXONOMY_UNCERTAIN | 代码不能核实或语义有争议，核对规范清单和数学目标 |
| DIFFICULTY_UNCERTAIN | 真实编辑难度争议，人工定级；不因来源没评级而加 |
| CALCULATOR_POLICY_UNCERTAIN | 已有要求的证据不清/冲突；双方未指定可空，不机械加 |
| FIGURE_REQUIRED / FIGURE_MISSING / FIGURE_TEXT_UNCLEAR | 保留图形依赖，补全或核对图形资产 |
| RIGHTS_REVIEW_REQUIRED | 使用依据未确认，不可发布 |
| DUPLICATE_SUSPECTED | 人工核对是否同一题，不能换ID绕过查重 |

数学统一用 `\(...\)` / `\[...\]`，不使用 `$...$` / `$$...$$`，强调符号不混进公式。不把可转录公式截图替代文本。文本PDF提取后仍看原页；扫描件明确记OCR，逐符号核对分数线、根号、积分界限、绝对值、希腊字母等。跨页记录完整物理页范围，生产保存起始页，完整范围作为证据。

修题干/选项/答案/解析重做数学与显示核对；换来源/页码重新核对来源和转录；换标签核对分类；换图片核对使用依据与显示。发布前额外抽查至少10%的普通题及全部hard/图形题的最终修订是否落入实际版本；这是复核导出/保存结果，不替代逐题首审。原始来源、AI原始结果、真实人工决定和修订前后值必须随批归档。

## 后台确认和修订

预览 → 保存draft → Saved drafts回读 → Publish看当前版本并确认一次，每次最多20题。旧四关卡/逐flag表已从当前发布流程删除，不再重复填写；按钮可点不代表数学、许可和显示自动正确。

Edit仅支持八项元数据，不能改题干/选项/答案/解析/图片。新建且未发布的错误草稿可由管理员明确删除后同ID重导；有发布历史先撤回并交内容修订处理，保留身份和历史，不能改ID绕过查重。后续以当前保存值为准，不恢复旧XLSX空值。

过期或响应不明先回读，不盲目重试。草稿已存、已发布、学生端已验收分别记录。本SOP不承诺未经测量的审核速度。
