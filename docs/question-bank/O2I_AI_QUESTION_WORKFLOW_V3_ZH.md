# O2I AI workflow v3：对齐当前题库

保留“两次独立处理、四步交付”。导入字段以 [Schema](O2I_QUESTION_IMPORT_SCHEMA.md) 和现有空白模板为准；本版替代 V2 中逐项填写发布确认的操作说明。旧 ZIP/HTML 包未更新，请直接使用下列四段 prompt。旧 V1 文件不变。

## 共同规则

- 当前草稿中人工已保存的元数据优先于旧 XLSX/AI 候选。复核已有题时必须取得当前值；拿不到就写“未核对当前草稿”，不能用原文件空值断言网站丢失字段。
- difficulty 是编辑难度，使用 easy/medium/hard。calculator_policy 使用 no_calculator/calculator_allowed/calculator_required 或空值；管理员明确指定的练习政策可使用，但不能伪称来源原文。
- 只对实际缺失、矛盾或无法确认的事项标 uncertainty，不给全部题机械添加相同 flags。
- 原始证据保留；已解决的 flags 在人工决策中记录解决结果，不再作为当前待办。不删除原始证据来伪装“从无问题”。
- AI 输出 human_review_status=pending，不代替人发布。网站发布只预览当前版本与一次确认，不重新填写历史审核表。

## 1. Chat 1：提取与标签

上传同批原题 PDF、答案/解析、空白模板、Schema、taxonomy，并指定题号或页码范围。复制：

```text
你是 O2I 题库整理员。只处理我指定的附件和范围，先列出实际能读取的文件。缺少必要来源时指出缺失，不补造题目。
按 Schema 保持 Questions、Options、Instructions 三个 sheet 和全部表头。转录题干、选项和来源定位，按真实题号匹配答案；检查正负号、上下标、极限方向和必要图形。来源没有解析时，AI 解法标为草稿，不冒充来源解析。
根据 taxonomy 提供 Topic、Skills、AB/BC/BOTH、表示方式及 easy/medium/hard 候选。只有真实冲突或依据不足才加 uncertainty，并写明具体问题。管理员已指定的难度/计算器政策使用当前值，注明为人工设定；来源和管理员均未指定计算器政策时留空，不猜。
输出 [BATCH]_Draft.xlsx 与 [BATCH]_Evidence.json，保留原始证据、候选依据和未解决问题。所有审核状态保持 pending，reviewed_by/at 留空，不声明人工批准。
```

## 2. 新 Chat 2：先盲审

上传相同原始输入，暂不上传 Chat 1 输出。复制：

```text
独立复核本批指定题目，不读取第一轮结果。
从原题独立求解，核对唯一正确选项、来源配对、必要图形、Topic/Skills 与难度候选。计算器政策使用来源明确要求或管理员指定值，二者不同则说明区别。
保存 [BATCH]_Independent_Review.json，逐题记录结果和具体疑点。没有来源难度评级本身不是错误，easy/medium/hard 是编辑判断。先保存独立结果，再等待第一轮输出，不提前声称两轮一致。
```

## 3. Chat 2：差异卡与人工决定

再提供 Chat 1 输出；复核已有草稿时一并提供当前元数据。复制：

```text
比较已保存的独立复核与第一轮结果，生成逐题审核卡。直接展示题干、全部选项、答案、解析及当前元数据；一致项简洁展示，只把真实差异、数学疑点、缺图或定位问题放入待处理队列。
人工已保存的 difficulty、calculator_policy、Topic 等值优先于旧候选；若与独立数学分析冲突，明确指出并请人工决定，不能静默覆盖。
人工可选择保留、修改元数据或排除。仅对修改或真实异常填写说明。题干/答案/解析的修订需进入导出 XLSX，不声称网站现有 Edit 可以修改这些内容。
保存 [BATCH]_Human_Decisions.json：最终选择、修改前后值、已解决/仍未解决的问题及明确的人工作出决定的记录。没有收到人工决定的题保持待定，不代替人工勾选。
```

## 4. Chat 2：最终草稿与校验

复制：

```text
依据实际人工决定导出 [BATCH]_Post_Review_Draft.xlsx，只纳入人工保留且不存在未解决内容错误的题。使用已确认的最新元数据，不恢复旧候选或旧空值。
保持原 sheet/表头和 Schema。human_review_status 仍为 pending，人工决策保留在证据文件中；不伪造审核人或正式发布记录。
检查唯一 external_id、题目与选项匹配、唯一正确答案、选项数合法、题干/解析非空、难度/课程范围/Topic/Skills 合法、来源可定位、必要图片可用、数学渲染无错误。calculator_policy 可空但报告数量，已有人工值不得丢失。
交付最终 XLSX、人工决策和简短校验报告，写实际题数/选项数，不拿题号范围代替数量。未解决项单列并排除。网站导入后核对预览和保存草稿，发布前只核对当前题目与标签并确认一次。
```

## 为自适应补题

先补一个试点 Topic 至至少 15 道人工审核通过的题，三个难度各至少 5 道。不能为凑配额改难度；优先清晰来源和可复核解答，采样检查同难度的一致性。

本文仅更新操作协议，不表示真实题复核、扩题或“30题10分钟”效率目标已完成。
