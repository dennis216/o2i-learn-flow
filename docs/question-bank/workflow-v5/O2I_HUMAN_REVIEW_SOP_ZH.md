# 审核卡怎么用

1. 先看冲突题，再看一致题。核对原 PDF 的题号、页码、题干、选项和符号。两次 AI 一致也可能同错。
2. 自己先判断答案，再展开答案和解析。重点看条件、关键推导和唯一正确项；AI 写的解析也要核实。
3. 看 Topic、Skill、课程范围和难度。可以直接修改，不需要另填一套审核表。
4. **每题都选计算器政策**：禁止、允许或必须使用。可以由你指定 O2I 的练习政策；有别于来源时，在修改意见中说明。
5. 修正内容后选“通过”并保存本卡；没修好选“需修改”，不收录选“暂不收录”。默认待审核，不批量替人通过。
6. 完成后要求导出。只有已保存且通过的题进入最终 XLSX，五项审核状态写 reviewed，名字来自 Reviewer，时间记录实际审核当天。

保存本卡应保存题目修改、全部标签、计算器政策、决定、意见、审核人和时间。刷新或离开前下载审核结果 JSON；只选择但没保存不算提交。修改已经保存的卡后须重新保存，更新时间；单纯重新导出不改时间。

source_rights_status=reviewed 表示你已查看来源及使用说明，不等于自动取得版权许可；使用依据不明时不要发布。render_review_status=reviewed 表示卡片显示已查看，上传网站后仍要看一次实际公式和图片。需要图片的题必须有完整、可访问且获授权的图片。

最终上传只会创建未发布草稿。给出 Reviewer 名字不会自动通过题目，也不会自动发布。
