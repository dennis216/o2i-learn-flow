# Brian：Arena 体验与窗口适配记录（#41 / #42）

本批只更新 `brian` 个人分支与预览站，不修改数据库，不合并 `test-work` 或 `main`。GitHub 上本轮的协作评论已改为中文。

## 已实现

- 冲刺、技能、攻击使用原创像素小图案，下方保留中英文像素文字；暂停使用像素暂停图案。按钮表面半透明，按实际画布位置计算刘海、手势条安全区，保留边缘间距。
- 触控设备开局继续尝试原生全屏及横屏锁定；不支持时展开网页播放器并提示手动横屏。退出按钮在手机竖屏的暂停／答题弹窗上方仍可点击。
- 主武器默认自动攻击。开局设置、暂停设置可切换手动模式：按住攻击按钮、鼠标左键或 F 连发，松开、取消触摸、暂停时停止新增射击。辅助武器保留自动行为，偏好保存在当前设备。
- 封面 AP Calculus AB & BC 的原文内容保留；长说明使用普通正文的字体度量和细描边，减轻原先白字粘连。四个角色的技能提示和 Unit 提示使用同一方案。
- Upgrade 名称保持像素字体，介绍、升级预告等使用清晰正文。选枪说明和天赋文字去掉方框，用名称颜色和下划线标识选中项。
- 冲刺／技能 CD 使用像素字体，并显示对应语言。左下角显示已选关卡进度及当前 Unit。
- 经验晶体增加亮轮廓、亮点和轻微光晕，提高与地板的区分度；吸取步长限制在目标距离内，避免越过角色后反复来回。
- 复用磁铁拾取物：放大像素图标，加脉动标记；普通怪物磁铁掉落概率约 2%。约 25 秒开始尝试生成附近的地面磁铁，之后约 30–40 秒尝试一次，附近已有磁铁时不堆叠生成。拾取后约 8 秒内将经验吸取范围扩大至当前基础范围的 3 倍，并显示倒计时。可与已有拾取范围升级组合；爱心回血和经验数值不变。

## 检查与修复

- 手机竖屏的攻击、冲刺、技能改为底部排列，避免与上方全屏按钮重叠；较宽画面保留右侧分组布局。
- 修复手机窄屏暂停遮罩挡住退出全屏按钮的问题，并为弹窗内容预留顶部空间。
- 安全区按实际画布与屏幕的交集计算；画布外已有黑边时，不重复计算刘海或底部手势条。
- `npm run test:arena`：22 项通过，包含实际拾取函数及开火函数的隔离回归测试。
- 浏览器模拟：1180×820、820×1180、390×844、844×390，中英文各一轮，验证自动／手动攻击、保存偏好、移动与攻击同时操作、松手／取消、技能／冲刺、CD 字体、关卡标记、按钮边界与非重叠。
- 桌面 1×、2× 像素密度及手机，中英文检查封面、全部角色技能说明、选枪和 Upgrade 名称／介绍字体。
- 原生全屏与模拟不支持原生全屏两种路径，在横竖屏、中英文中验证手动攻击布局、安全区、暂停、手动退出、浏览器退出和页面滚动恢复；另验证触控开局自动请求原生全屏。
- TypeScript、相关文件 ESLint、生产构建和 `git diff --check` 通过。

这些检查使用本地合成状态，不登录或写入生产账号。真实 iPhone／iPad Safari 的手感、浏览器全屏与横屏限制仍需 Brian 实机验收；不把模拟结果等同于所有设备无 bug。
