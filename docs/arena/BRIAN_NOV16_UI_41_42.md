## 手机横屏修正（2026-11-16）

- 页面初始化会先展开游戏；之前这导致点击开始时提前返回，跳过原生全屏和方向锁定请求。
- 现在触屏设备点击开始就尝试升级为原生全屏，成功后请求 landscape；已经处于原生全屏时复用该状态。
- iPad/iPhone 继续使用页面模式，防止移动操作导致原生全屏退出和尺寸错乱。不支持方向锁定的浏览器需要用户关闭系统方向锁并手动横放；不能承诺网页自动旋转这些设备。
- 原生请求被拒时保留页面布局和横屏提示；原生全屏退出后也保留稳定的展开页面。
- 拆分版本新增 3 项衔接/回退行为测试，Arena 共 78/78 通过。WebKit/Chromium 的安卓方向 API 模拟和 iPad/iPhone 手动横放、移动稳定性共 5 组检查；模拟不等于实体设备自动旋转验收。

- 关卡文字改为裁去字体透明边距后绘制，按可见字形高度扩展并居中，不再使用会让文字凸出底边的固定 22 像素框。中英文及多位关卡编号均检查内部留白。
