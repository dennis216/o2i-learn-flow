# Brian：iPad / iPhone 触摸与窗口适配（#41 / #42）

2026-11-15，个人分支 brian。Brian 确认 Chrome 上的问题是摇杆一动就退出全屏、尺寸混乱；本轮优先处理适配。

## 本次行为

- iPad、iPhone（含桌面模式 iPad）的 Safari / Chrome 使用页面铺满模式，不自动请求系统原生全屏。浏览器工具栏可能保留，游戏按可见区域计算大小；iOS 不支持可靠强制横屏时提示旋转设备。
- 画布阻止触摸滚动、双击与系统手势的默认处理；取消指针或丢失捕获时复位摇杆和手动开火状态。
- 意外退出原生全屏时，触摸设备保留页面铺满布局；点击 Exit 才还原嵌入布局。
- React 宿主跟随 visualViewport、窗口旋转和浏览器工具栏变化调整 iframe；画布保持 16:9。
- 升级卡片窗口上限由普通面板的 780px 扩至 1180px，使用宿主可用宽度；600–1099px 下三/四选一为两列，说明占满卡片宽度。
- 短屏/手机技能选择使用可见页面高度，默认同时显示全部选择与核心效果；搭配、下一级和前一道题可通过“查看详情”主动展开，不强迫玩家滚动才能选技能。
- 手机结算窗口取消撑出边界的入场缩放动画，保留顶部对齐、内部滚动。
- 六把枪的网格样式仅作用于选枪页，恢复四英雄的原布局。
- 已完成的两把新主武器各七个专属天赋及暖色伤害数字一并保留；中文字体补全。
- **刷怪逻辑与上一已发布版本完全一致**，Brian 已撤回刷怪调整要求。
