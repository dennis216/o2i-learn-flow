# Brian：武器扩展、全技能插图和试玩修正（#41 / #42）

仅在 `brian` 分支及个人预览站修改。没有改正式站、test-work 或生产数据库。

## 本轮六项修正

1. 手持武器缩小为 5–9 像素宽的独立图案，狙击枪有长枪管与瞄镜，步枪有短枪管和弹匣；后加入的连弩与炮也有对应手持图。子弹起点、开火闪光与可见枪口共用同一套旋转坐标，火光跟随角色移动；隐身时手持武器一起淡出。
2. 四种新地图的精英怪分别使用雪怪、沙漠守卫、雨林菌兽、书页守卫轮廓，保留精英皇冠和原生命/伤害/掉落规则。
3. 磁铁图画改为 10×9，爱心为 9×8，仅大一个像素；移除过大的光圈。
4. 隐藏特殊区域和已领取增益的实时倒计时数字，保留名称、屏外箭头、首次说明和实际的限时时长。磁铁及英雄技能冷却显示不受影响。
5. 数学书减速区域中的瓶子明确画出蓝色墨水、瓶口和反光，地面墨水增加深蓝色层次与浅色水纹。
6. 截图中的红色提示来自出题 RPC 返回 `empty`。仓库里的 SQL 会排除同一局已发出的题目，并在单局 100 题时返回 empty；从截图本身不能确定生产题池的实际数量。

### 题目用完后的流程

- 把 `empty` 与网络失败、频率限制分开，不再把题池用完当作红色故障。
- 题池用完后给出中英文说明，之后仍可正常三选一升级，不增加已答/答对题数。
- 本局记录题池用完，不在每次升级时重复发空请求；新一局清空该状态。
- 没有重建答题 run ID 绕过限制，没有重复刷同局已答题，也没有改题库或生产 RPC。
- 网络错误和限流仍走原基础奖励降级路径。

| 向量连弩 / Vector Crossbow | HP 95、速度 64、暴击 10% | 每箭 17 → 29，双箭；冷却 0.95 → 0.81 秒 | 窄幅精准双箭，基础穿透 1 |

## 十项新通用被动/状态强化

均最多三级，升级卡显示具体累计数值：

- 正交透镜：每级范围 +4%。
- 电阻引理：每级对感电目标伤害 +4%，无感电来源时不作为新技能出现。
- 霜冻引理：每级冰冻延长 0.15 秒、对冰冻目标伤害 +3%，无冰冻来源时不作为新技能出现。
- 卡塔兰路径：每级经验 +3%、拾取范围 +6%。
- 紧致边界：每级最大生命 +8，恢复同等生命；双重升级也正确处理恢复。
- 平衡守护：低于半血时每级额外减伤 4%。
- 链式印记：主武器命中每级有 7% 概率附加 1.5 秒标记。
- 雅可比疗愈：每级爱心治疗 +8%，不超过生命上限。
- 泰勒余量：每级英雄技能冷却 -3%。
- 边界薄层：冲刺结束后一秒，每级额外减伤 4%。

保留原武器/被动槽位上限，减伤按乘法叠加，旧伤害及暴击上限不变。

## 全部技能插图

不是只换新增项目：100 个武器/天赋/被动条目、13 个进化、22 个定理，以及四位英雄的 8 个主动/被动技能，共 143 张插图。

采用 24×24 原生彩色像素小画：枪械、弓、炮、护盾、药瓶、靴子、透镜、晶体、卷轴、书本等有轮廓、暗部、亮面和地面投影。旧符号作为小铭文保留辨识；进化增加金色与能量/额外碎片，定理封面显示所需组件的缩图。图鉴和升级卡正常显示 48×48，HUD 缩小显示；长图鉴取消弹跳缩放动画，避免手机打开瞬间越出屏幕；像素禁用平滑，缓存复用避免每帧重画。
