**参考**

- [AlterLab-IEU/AlterLab_GameForge](https://github.com/AlterLab-IEU/AlterLab_GameForge)：`docs/game-design-theory.md`（一次只教一个机制，不要两个系统同时出现；说明超过两句话就是设计问题）、`genre-packs/roguelike/PATTERNS.md`（"信息过载"：系统一次全给，新手还没到好玩的部分就走了，Hades 每局只引入一个新机制）、`skills/agents/game-ux-designer/references/hud-and-menu-patterns.md`（HUD 分层：第 1 层常驻且只有 3–4 项，第 2 层用到时才出现、平静时淡出，第 3 层放暂停页）。
- [gamedev-skills/awesome-gamedev-agent-skills](https://github.com/gamedev-skills/awesome-gamedev-agent-skills)：`game-ui-ux`（地图上的标记会挡住战斗）、`game-feel`（打击感分小/中/大三档，震屏只给真正的冲击）、`level-design`（锯齿节奏：高峰前要有喘息）。
- 弹幕类游戏试玩反馈（itch.io）：自己的特效和伤害数字会盖住敌人的子弹；玩家的攻击要和敌人的攻击一眼分开。

**改了什么**

| 乱在哪里 | 依据 | 改法 |
|---|---|---|
| 开局 3 块题碑、巢穴、门一起出现，前 30 秒连答三题 | 一次只教一个机制；信息过载 | 题碑**分批开放**：新一局只有 ★，答过 1 块才开 ★★，答过 2 块才开 ★★★。所有题碑**共用一个冷却**：答完哪块，全部熄灭（★ 25 秒、★★ 35 秒、★★★ 45 秒）。任何答题或面板关掉后 8 秒内题碑不会亮，题不会连着来 |
| 小首领巢穴一开局就在 | 一次只出现一个新东西 | 巢穴先藏着：第一个世界开过第一个宝箱（至少 30 秒）或满 2 分钟才出现，之后的世界 45 秒；出现时一条横幅写方向。周挑战"首领猎人"的第二个巢穴等第一个打完或 1 分钟后 |
| 隐藏门很早就可能误撞进去 | 同上 | 打败本世界的小首领后（或第一个世界 200 秒、之后 90 秒）才能被发现，出现时提示大概方向 |
| 6 个第一次说明都是暂停弹窗，3–4 句话 | 情境教学；超过两句就是设计问题 | 改成左下角猫头鹰小提示（和 Brian 的新手提示同一个框），**不暂停**、6 秒后消失、每条最多两句，每台设备只出现一次；排队，不会两条叠在一起 |
| 横幅一个顶掉一个 | 同一时间只说一件事 | 横幅排队，两条之间至少 2 秒 |
| 边缘箭头常驻 2–3 个 | 标记会挡住战斗；目标要清楚 | 最多 2 个：1 个目标（最近的、**屏幕外**的已亮题碑——站在 ★ 旁边时它会指向 ★★；否则是刚出现或正在打的巢穴，之后每分钟提醒 8 秒；否则是已发现的门）+ 1 个掉落物。看得见的东西不再标 |
| 右上角越来越长：宝箱文字、算力图标、"本周挑战" | HUD 分层 | 宝箱改成小宝箱图标 + 细条，不写百分比；涨的时候亮 2.5 秒，平时变暗，有宝箱掉在地上时闪。算力和本周挑战挪到暂停页的构筑列表（火花仍在单元技能图标上显示黄框） |
| 被动技能也会暴击，出大号"90!"、暴击火花和震屏 | 打击感分档；自己的特效会盖住敌人子弹 | 单元技能和装备的伤害**不再暴击**，按平均暴击折算进伤害（强度不变），数字用淡色小字，不再每次命中都"嗒"一声；地面特效整体变淡（×0.75），渐近线改细线，去掉地上的"x=a"文字 |
| 题碑没准备好时也画圈、画进度点 | 平静时淡出 | 冷却中只画一块暗石头，走到 90 px 内才显示进度点；亮了才有光圈 |

## Dennis 的反馈 → 这一轮怎么做

| 反馈（2026-11-18） | 做法 |
|---|---|
| 技能和知识点联动性不强 | 每个单元有自己的**单元技能**，机制就是这个知识点（夹逼定理把敌人夹住、渐近线让敌人越靠越慢、链式法则一环比一环强……），卡片上写清楚对应的数学 |
| 极限应该有特定技能，过了这个单元就没有 | 单元技能只在当前单元出现；击败首领换单元后失效。升到 Lv 3 的技能留下本局 +3% 伤害（"知识沉淀"） |
| 简单题、难题分区域；难题给强技能 | 每张地图 3 块**题碑**：★ 在出生点附近，★★ 中间，★★★ 在远处角落。走上去主动答一道当前单元的题。★★ 奖励里有 1 个单元技能，★★★ 有 2 个，外加进化/定理/稀有奖励 |
| 强技能和小技能碰撞出火花 | 隐藏房间给的**算力技能**和对应的单元技能同时拥有时触发**火花**（例：夹逼定理 + 根式有理化 → 有理化夹逼）；配对按数学关系设计，卡片和暂停页都会显示 |
| 小怪掉少量经验，主要靠题目和宝箱，题目加速宝箱 | 普通小怪经验 ×0.6（精英、首领不变）；右上角新增**宝箱进度**，主要靠答对题推进，攒满掉落**知识宝箱**（3 选 1） |
| 主动去小 Boss，按背景生成；打败掉装备（火箭炮、激光），和小 Boss 对应 | 每张地图 1 个**小首领巢穴**，走近才醒：坐标世界的机械兵（Dennis 说的"机械风→机器人"）→ 激光炮；沙漠火箭蝎 → 火箭炮；雨林蟹将军带 4 个虾兵 → 泡泡炮；冰原雪怪 → 霜冻冲击；书页墨水章鱼 → 墨水炸弹。2 个装备槽，同一件再拿到升级 |
| 主动去隐藏房间，为当前知识点打基础（根式有理化、算力） | 每张地图 1 扇**隐藏门**，走到 70 px 内才显形。里面 3 道本单元的前置计算题（本地生成：根式有理化、因式分解、指数律、斜率、复合函数、三角值、面积与求和），答对 ≥2 题选一个永久算力技能 |
| 周挑战 | 主菜单新增"本周挑战"：按 ISO 周固定单元、英雄、武器和 2 条规则，本地记录本周最佳 |
| 海王 + 极限做大 Boss | 大首领按当前单元选（第 1 单元 → DNE 领主，第 2–5 → 切线爵士，第 6–8 → 黎曼巨像；同单元连续两次时回到原来的顺序），名字加世界前缀（沙海·、雨林·、冰原·、书页·） |

## 数值

| 项目 | 数值 |
|---|---|
| 普通小怪经验 | ×0.6（精英、首领、小首领不变） |
| 宝箱进度：题碑答对 | ★ +18% · ★★ +28% · ★★★ +40% |
| 宝箱进度：升级题答对 | ★ +12% · ★★ +18% · ★★★ +26% |
| 宝箱进度：其他 | 击杀 +0.2% · 精英 +3% · 小首领 +35% · 算力房全对 +20% · 分解装备 +30%；答错不加 |
| 题碑冷却 | 共用：答完 ★ / ★★ / ★★★ 后全部熄灭 25 / 35 / 45 秒；开局 2 秒后 ★ 可用；答题或面板关闭后 8 秒内不亮；★★ 在答过 1 块后开放，★★★ 在答过 2 块后开放 |
| 小首领巢穴出现 | 第一个世界：开过第一个宝箱且满 30 秒，或满 120 秒；之后的世界 45 秒 |
| 隐藏门可被发现 | 本世界小首领被打败后，或第一个世界 200 秒、之后 90 秒 |
| 题碑附近刷怪 | ★★ 区 ×1.25 · ★★★ 区 ×1.6 |
| 题碑出题 | 用现有 `arena_practice_next_question` 的 `_tier` = 星级，`_prefer_current = true`（优先当前单元） |
| 单元技能 | 每个 3 级；伤害 × 全局伤害 ×（1 + 时间/300 秒），和其他技能一样会随局内成长 |
| 算力技能 | 每个 2 级：有理化（对精英/小首领/装甲 +8%）、因式分解（伤害 +4%）、斜率（移速 +5%）、指数律（经验 +6%）、复合函数（单元技能冷却 −8%）、三角值（单元技能范围 +10%）、面积求和（宝箱进度 +8%） |
| 小首领 | 生命约 650 × 时间成长 × 敌人难度；离巢 150 px 被拉回，玩家跑出 320 px 回巢回血 |
| 装备 | 2 槽、最高 Lv 3；满槽时可以换下一件或分解 |

所有单元技能、算力、装备、小首领、周挑战规则的中英文和具体数字都在 `arena-knowledge.js` 顶部的表里，调平衡直接改表。

## 代码结构

- `public/games/arena-knowledge.js`：数据表、算力题生成、周挑战、地图布局，以及 `createKnowledgeFlow(api)` 运行时。
- `limit-arena.js` 里的挂钩（都是一两行）：开局 `On`、属性 `Jo`、射速 `za`、伤害 `At`、击杀经验与 `Jn`、每帧 `wi`、换单元 `Xn`、刷怪 `fi`、拾取 `mi`、领取奖励 `Li`、首领 `cs` / `Pi` / `Bi`、结算 `_a`、绘制 `ji` / `Ji` / `o1`、图标 `illustratedIcon`、推荐 `recommendUpgrade`、面板 `Bt.quiz` / `reveal` / `reroll` / `key` / `menu` / `buildHTML`。
- `api` 对象全部用取值函数传入，测试改绑定（如 `oe`、`Bt`）时新玩法也跟着用替身。
- 中文像素字体子集已重建（新增 75 个字；Cubic 11 没有"轭"，文案改成"分子分母同乘"）。`subset-zh-font.py` 和中文字体测试都扫描新文件。
- `public/_headers` 给新文件加了 `no-cache`。
