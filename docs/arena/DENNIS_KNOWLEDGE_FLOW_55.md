## 现在的玩法（第四轮精简后，2026-11-19）

核心只有一句话：**打怪 → 答题 → 变强，题越难技能越强。** 学生在原版之外只需要新学 3 样东西：

| 东西 | 怎么玩 |
|---|---|
| 题碑 ★ / ★★ / ★★★ | 走上去答一道当前单元的题（题库真题，进学习记录）。答对给本单元技能：★ 1 张单元技能卡 + 2 张普通卡；★★ 2 张单元技能卡 + 1 张普通卡；★★★ 2 张单元技能卡（**一次升 2 级**）+ 1 张进化/定理卡。新一局只开 ★，答过 1 块开 ★★、答过 2 块开 ★★★；所有题碑共用冷却 |
| 单元技能 | 每个单元 2–3 个，机制就是这个知识点（夹逼定理把敌人夹住、渐近线让敌人减速……），最高 Lv 3；进入下一单元就消失 |
| 小首领 → 装备 | 每个世界 1 个按背景生成的小首领（机械兵 → 激光炮、火箭蝎 → 火箭炮……），第一个世界答过 2 块题碑（至少 30 秒）或满 2 分钟才出现。打败掉对应装备；2 个装备槽，同一件再拿到升级；满槽时换下一件或保留现有装备（生命回满） |

做题入口只有两种：升级题（原版）和题碑题，都是题库真题。

**第四轮砍掉的**（Dennis："重点不清晰、有点乱"）：宝箱条和知识宝箱（和题碑重复，都是答题换技能）、隐藏算力房和算力技能（第三种做题方式，题是本地生成的，不进学习记录）、火花组合（依赖算力）、知识沉淀（看不见的被动加成）、本周挑战（另一个模式）。代码都在 git 历史里（`69277ab` 及之前），要加回来可以从那里取。以后如果想要"碰撞出火花"的感觉，可以改成"两个单元技能都到 Lv 3 就触发"，不需要新系统。

### 现在的数值

| 项目 | 数值 |
|---|---|
| 普通小怪经验 | ×0.6（精英、首领、小首领不变） |
| 题碑冷却 | 共用：答完 ★ / ★★ / ★★★ 后全部熄灭 25 / 35 / 45 秒；开局 2 秒后 ★ 可用；答题或面板关闭后 8 秒内不亮 |
| 题碑附近刷怪 | ★★ 区 ×1.25 · ★★★ 区 ×1.6 |
| 题碑出题 | `arena_practice_next_question` 的 `_tier` = 星级，`_prefer_current = true` |
| 单元技能 | 每个 3 级；伤害 × 全局伤害 ×（1 + 局内时间/300 秒）；不暴击，平均暴击折算进伤害 |
| 小首领出现 | 第一个世界：答过 2 块题碑且满 30 秒，或满 120 秒；之后的世界 45 秒 |
| 小首领 | 生命约 650 × 时间成长 × 敌人难度；离巢 150 px 被拉回，玩家跑出 320 px 回巢回血 |
| 装备 | 2 槽、最高 Lv 3 |

单元技能、装备、小首领的中英文和数字都在 `arena-knowledge.js` 顶部的表里，调平衡直接改表。

### 现在的新手说明

题碑（★、★★、★★★ 各一条）、单元技能、小首领巢穴、装备第一次出现时，左下角猫头鹰小提示（和 Brian 的新手提示同一个框，不暂停，每条最多两句，每台设备一次）。文案在 `HINTS` 表里，已读记在本机 `regionSeen` 的 `kfh:` 键下。

## 第三轮：退出全屏 + 管理员测试速度（2026-11-18 晚）

**退出全屏还有问题**：截图里网站导航栏压在游戏上面。原因是页面切换动画 `.page-enter` 用了 `animation-fill-mode: both`，动画结束后仍保留一个层叠上下文，把全屏游戏（`fixed`、`z-100`）关在里面，于是 `z-40` 的导航栏反而在上面（用最小页面复现过：`both` 时左上角是导航栏，`backwards` 时是游戏）。
- `src/index.css`：`.page-enter` 改成 `backwards`（看起来一样，动画结束后不再留层叠上下文）；游戏全屏时 `html.arena-expanded` 顺便隐藏导航栏。
- `src/pages/Arena.tsx`：退出全屏后滚回页面顶部，避免导航栏盖住游戏顶部。
- `limit-arena.js`：触屏笔记本（有鼠标/触控板）按 Esc 退出原生全屏后直接回到网页；只有没有鼠标的手机/平板才保留"页面全屏"（新增 `hasFinePointer()`，测试覆盖）。

**管理员测试速度**：单元与难度页最下面多一行"测试速度（仅管理员）：关闭 / ×2 / ×4"。网站给管理员写 `localStorage["cq-arena-admin"]`，学生看不到这一行（就算手动写，也只是加速自己本地的一局）。
- 选 ×N 后：经验 ×N；`limit-arena.js` 里新加 `runT()` = 局内时间 × N，敌人血量/速度/伤害成长、刷怪密度、击杀经验成长、武器随时间成长、出题难度进度、首领血量都改用它；首领 180/N 秒来一次（打完后至少隔 75/N 秒）。所以在任意时刻，敌人强度和玩家等级都相当于正常局的 N 倍时间点，平衡不变，只是快进。
- 知识玩法也跟着快：题碑冷却、开局、答题后休息、巢穴出现、隐藏门解锁都 ÷N；单元技能和小首领的时间成长也用 ×N 的时钟。
- HUD 右上显示黄色"测试 ×N"；结算页写"测试模式 ×N：这局不计入记录"，不写本地最佳/前五、不算周挑战；周挑战局永远是正常速度。
- 同一个机器人：正常速度 81 秒还是 Lv 1、没有首领；×4 在 41 秒 Lv 4、30 秒小首领出现、45 秒首领来袭。

## 第一轮：Dennis 的反馈 → 怎么做（历史）

| 反馈（2026-11-18） | 做法 |
|---|---|
| 技能和知识点联动性不强 | 每个单元有自己的**单元技能**，机制就是这个知识点（夹逼定理把敌人夹住、渐近线让敌人越靠越慢、链式法则一环比一环强……），卡片上写清楚对应的数学 |
| 极限应该有特定技能，过了这个单元就没有 | 单元技能只在当前单元出现；击败首领换单元后失效。升到 Lv 3 的技能留下本局 +3% 伤害（"知识沉淀"） |
| 简单题、难题分区域；难题给强技能 | 每张地图 3 块**题碑**：★ 在出生点附近，★★ 中间，★★★ 在远处角落。走上去主动答一道当前单元的题。★★ 奖励里有 1 个单元技能，★★★ 有 2 个，外加进化/定理/稀有奖励 |
| 强技能和小技能碰撞出火花 | 隐藏房间给的**算力技能**和对应的单元技能同时拥有时触发**火花**（例：夹逼定理 + 根式有理化 → 有理化夹逼）；配对按数学关系设计，卡片和暂停页都会显示 |
| 小怪掉少量经验，主要靠题目和宝箱，题目加速宝箱 | 普通小怪经验 ×0.6（精英、首领不变）；右上角新增**宝箱进度**，主要靠答对题推进，攒满掉落**知识宝箱**（3 选 1） |
| 主动去小 Boss，按背景生成；打败掉装备（火箭炮、激光），和小 Boss 对应 | 每张地图 1 个**小首领巢穴**，走近才醒：坐标世界的机械兵（Dennis 说的"机械风→机器人"）→ 激光炮；沙漠火箭蝎 → 火箭炮；雨林蟹将军带 4 个虾兵 → 泡泡炮；冰原雪怪 → 霜冻冲击；书页墨水章鱼 → 墨水炸弹。2 个装备槽，同一件再拿到升级 |
| 主动去隐藏房间，为当前知识点打基础（根式有理化、算力） | 每张地图 1 扇**隐藏门**，走到 70 px 内才显形。里面 3 道本单元的前置计算题（本地生成：根式有理化、因式分解、指数律、斜率、复合函数、三角值、面积与求和），答对 ≥2 题选一个永久算力技能 |
| 周挑战 | 主菜单新增"本周挑战"：按 ISO 周固定单元、英雄、武器和 2 条规则，本地记录本周最佳 |
| 海王 + 极限做大 Boss | 大首领按当前单元选（第 1 单元 → DNE 领主，第 2–5 → 切线爵士，第 6–8 → 黎曼巨像；同单元连续两次时回到原来的顺序），名字加世界前缀（沙海·、雨林·、冰原·、书页·） |
